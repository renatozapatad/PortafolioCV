Caso de Estudio Destacado

Diseño y Desarrollo de Plataforma E-commerce

Breve descripción de la actividad

Desarrollo de una plataforma E-commerce Single Page Application (SPA). El proyecto abarcó desde la creación de la interfaz de usuario para la navegación de productos y carrito de compras, hasta el desarrollo de la API y la base de datos para gestionar usuarios, autenticación y órdenes.

Desafío principal

El reto más grande fue implementar un sistema de autenticación seguro y gestionar el estado global de la aplicación (el carrito de compras de los usuarios) de manera eficiente y persistente entre recargas de la página, sin afectar el rendimiento de renderizado.

Solución propuesta

Para el frontend, implementé React utilizando Context API para el manejo del estado global del carrito. En el backend, construí una API REST con Node.js y Express, integrando JSON Web Tokens (JWT) para proteger las rutas privadas y encriptando las contraseñas con bcrypt.

Herramientas técnicas utilizadas

JavaScript, React.js, Node.js, Express, MongoDB (Mongoose), Git/GitHub (control de versiones) y Postman para pruebas de API.

Principales aprendizajes

Consolidé mi comprensión sobre el ciclo de vida de los componentes web y la comunicación asíncrona entre el cliente y el servidor. Además, aprendí a estructurar la lógica del backend separando las rutas, controladores y modelos (MVC).

Métricas de impacto logradas

  • Funcionalidad: 100% de las rutas críticas (checkout y perfil de usuario) protegidas exitosamente mediante middlewares de autenticación.
  • Eficiencia: Tiempos de respuesta de la API inferiores a 200ms en consultas a la base de datos.
  • Despliegue: Puesta en producción exitosa utilizando plataformas cloud.

Habilidades técnicas aplicadas

Desarrollo Full Stack JavaScript, diseño de APIs RESTful, modelado de bases de datos NoSQL y consumo de servicios web.

Justificación de elección

Decidí destacar este proyecto porque demuestra mi capacidad para construir una solución de software de principio a fin (End-to-End). Refleja autonomía técnica, conocimiento de tecnologías muy demandadas en el mercado laboral y la resolución de problemas lógicos propios de aplicaciones reales en producción.
